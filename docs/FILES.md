# Source file inventory — v0.3

185 project source/configuration/test/fixture/documentation files. Ignored virtualenvs, node_modules, databases, captures, builds and the user-provided APEX reference ZIP are excluded.

New implementation areas: `engine/ingestion`, extended memory/disk/network collectors, `engine/correlation/index.py` and `artifacts.py`, typed graph projection, additive import/schema/storage contracts, and Desktop artifact/process/parser-run views.

Generated verification evidence lives under `data/`, `desktop/test-results/`, `desktop/release/` and `dist/`; it is intentionally excluded from this source inventory.
